# NatuLife Store v1.0

Abra `index.html` no navegador.

## Colocar seu WhatsApp
Abra `script.js` e troque `55SEUNUMERO` por 55 + DDD + número, somente dígitos.

Exemplo fictício: `5545999999999`.

## Publicar no Netlify
1. Extraia o ZIP.
2. Entre no Netlify.
3. Faça implantação manual da pasta `natulife-store-v1`.
4. Abra o link gerado.

A primeira versão já possui busca, filtros, catálogo em PDF, vídeo, botões de WhatsApp e layout responsivo.
